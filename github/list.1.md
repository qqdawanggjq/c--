## 1.12 复习题
 
1. 对编程而言，可移植性意味着什么？
2. 解释源代码文件、目标代码文件和可执行文件有什么区别？
3. 编程的 7 个主要步骤是什么？
4. 编译器的任务是什么？
5. 链接器的任务是什么？
### 答案
1. 可移植性意味着什么？
指一份程序代码，不需要大量修改（甚至完全不用修改），就可以在不同的操作系统（Windows、Linux、Mac）、不同架构的CPU上编译运行。可移植性越好，程序适配不同平台的成本就越低。
​
2. 源代码文件、目标代码文件、可执行文件的区别
 
- 源代码文件：你亲手编写的  .c  文本文件，用人类能读懂的高级语言写成，不能直接运行，是编译器的输入材料。
​
- 目标代码文件：编译器处理源代码后生成的中间文件（Windows下是  .obj ，Linux下是  .o ），内容是机器能识别的二进制指令，但还缺少库函数、入口地址等拼接信息，无法直接运行。
​
- 可执行文件：链接器把目标文件和系统库文件拼接整合后，生成的最终程序（Windows下是  .exe ，Linux下是可执行文件），可以直接运行并完成功能。
 
3. 编程的7个主要步骤
​
4. 定义程序目标：明确程序要解决什么问题
​
5. 设计程序：规划输入输出、处理逻辑、程序结构
​
6. 编写代码：用编程语言写出具体实现
​
7. 编译：把源代码翻译成机器可识别的目标代码
​
8. 运行程序：执行生成的可执行文件
​
9. 测试与调试：验证功能是否正确，修复出现的错误
​
10. 维护与升级：后续优化功能、修复问题
​
11. 编译器的任务是什么？
将人类编写的高级语言源代码，逐行翻译成计算机能识别的二进制机器指令（目标代码）；同时检查代码中的语法错误，发现错误时给出报错提示，阻止生成错误的目标文件。
​
12. 链接器的任务是什么？
把编译生成的一个或多个目标代码文件，和程序用到的系统库函数、启动代码拼接整合到一起，解决函数调用、地址引用的关联问题，最终生成一个完整、可直接运行的可执行文件。
## 1.13 编程练习
 
我们尚未要求你编写 C 代码，该练习侧重于编程过程的早期步骤。
 
1. 你刚被 MacroMuscle 有限公司聘用。该公司准备进入欧洲市场，需要一个把英寸单位转换为厘米单位（1 英寸=2.54 厘米）的程序。该程序要提示用户输入英寸值。你的任务是定义程序目标和设计程序（编程过程的第 1 步和第 2 步）。
### 答案
```c
#include<stdio.h>
int main()
{
    printf("请输入英寸值\n");
    double n;
    scanf("%lf",&n);
    double cm=2.54*n;
    printf("%.2lf",cm);
    return 0;
}
```
